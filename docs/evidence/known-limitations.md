# 正式上线候选阻断项与已知限制

更新日期：2026-09-04。本文只记录当前代码和验证的真实状态，不构成上线批准。

## 已实现且经本地质量门验证

- 公开三栏目浏览、来源说明页、基础服务端筛选/游标分页、SPA 刷新 fallback。
- Git 版本控制的内容模块注册表、`module_key`、模块版本/修订快照、通用筛选投影和修订内容关联的 V6 迁移已经实现；竞赛、团队招募、学习资源与文章/经验共用内容内核。
- 管理员与合作方共用 Markdown 创作编辑器，支持写作/分屏/阅读预览、`.md` 导入导出、折叠发布设置和正文图片引用；服务端生成白名单安全文档，公开页面不渲染任意 HTML。
- 公开详情使用稳定 `/content/{id}`；旧分类详情地址保留兼容跳转。
- 公开投稿和合作方申请的幂等请求与异步表单重置回归。
- 管理员内容创建、送审、审核、发布、隐藏、重新公开、归档与恢复；合作方草稿、编辑候选修订、送审、配额和归属控制。
- 一次性短时激活令牌（仅存哈希）、账号资格检查、CSRF、幂等冲突、富文本白名单、CSP、审计摘要与留存清理任务。
- 公开写入有短窗口限流和 HTTPS 链接校验；限流键只在内存保留带密钥摘要，生产配置必须注入独立密钥。
- 合作方和管理员可仅对自己的候选修订上传 JPEG、PNG、WebP 正文图片；服务端会解码校验、重编码清除输入元数据、限制数量和总量，并以私有 S3/MinIO 键保存。新修订只继承正文仍引用且属于当前内容的媒体，支持删除和重排，跨内容引用会被拒绝。公开读取按已发布修订关联受控，未关联媒体由留存任务复核后清理。
- 公开内容使用受限语言值与中文显示标签；非中文内容必须留存原始标题。作者展示名、权利来源、署名转载与署名改编许可独立保存并在公开详情呈现，尚无空库 V5 或浏览器闭环证据。
- 本地与生产候选 Compose 配置解析、前端构建/测试、OpenAPI 核心结构/引用校验、后端 `mvn verify` 可运行包；当前完整 npm 依赖审计为 0 个已知漏洞。

## 未完成或尚未获得验证证据：阻止发布候选放行

1. 历史证据已在干净 MySQL/MinIO 上验证 Flyway V1–V5；当前环境没有可用 Docker 引擎，因此最新 V6 的空库和升级迁移、候选媒体继承以及 Compose 重建尚未复验。该项不能沿用旧证据判定通过。
2. S3/MinIO 私有媒体的基础写、读、删有历史 Testcontainers 证据；Markdown 正文图片的上传、重排/删除、发布、隐藏后拒绝读取、失败重试和孤儿清理仍缺少完整浏览器与应用 HTTP 集成证据。
3. OpenAPI 已有锁定版本的自动核心校验，但尚未实现契约驱动的前端类型生成；Playwright E2E、Java 依赖漏洞检查、许可证清单和前后端 SBOM 仍未完成。
4. 私密联系方式当前不收集；一旦产品批准收集，必须先实现应用层加密、受控密钥、删除周期和对应集成测试，不能直接启用预留数据列。
5. 备份、隔离恢复、应用回滚和发布演练仍无实际 RTO/RPO 证据。
6. 公开写入限流尚未完成反向代理链、重启行为和 7 天匿名限流事件留存的集成验证；它不能替代生产入口的 WAF/网关限流策略。
7. 通用筛选投影已经随修订写入数据库，但公开列表目前仍以搜索和既有栏目筛选为主，尚未交付由模块定义自动生成的全部筛选控件与多条件查询。

## 外部审批边界仍然有效

不创建腾讯云、COS、托管数据库、监控、邮件、DNS、证书或域名资源；不使用真实内容、联系方式、账号或社群入口；不推送远程仓库或对公网部署。
