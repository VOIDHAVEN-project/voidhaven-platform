# 正式上线候选阻断项与已知限制

更新日期：2026-09-05。本文记录当前代码与本地验证的真实状态，不构成生产上线批准。

## 本次已关闭的管理后台阻断项

- 图片上传控件不再嵌套表单。上传前先保存未同步草稿，上传成功后保持编辑页、插入受控媒体标记并继续自动保存；失败不会清空正文。
- 新增受控草稿媒体预览：管理员可查看待审图片，合作方仅可查看自己内容的图片，匿名和跨归属访问返回安全 404。
- 审核队列与审核详情分离。管理员在作出决定前可查看候选修订的完整 Markdown 渲染、图片、来源、版权、模块字段、归属与历史审核意见。
- 审核请求带候选修订版本；过期审核返回版本冲突。退回和拒绝要求原因，拒绝稿仅超级管理员可审计地重新开放。
- 审核通过与发布保持两个独立动作。发布前就绪检查明确列出来源、状态、媒体、版权和合作方配额阻断；配额不被管理员静默绕过。
- 管理员与合作方均使用真实 API 完成草稿、送审、退回、再编辑、通过、发布、隐藏、归档及恢复，不使用前端假成功。
- 合作方账号支持停用、恢复和永久撤销；账号资格在每次受限请求重新检查，停用后的既有会话在下一次请求立即失效。
- 投稿与合作方申请移除匿名“退回修改”死状态，只允许批准或拒绝，并支持分页、关键词与处理状态筛选。
- 管理工作台按内容、审核、公开投稿、合作方申请、合作方与账号、审计分区懒加载；内容和审核支持状态/模块筛选，审计支持操作人、对象、动作及时间范围筛选。
- 写操作统一使用 CSRF 与幂等键；并发相同请求返回 `REQUEST_IN_PROGRESS`，同键不同载荷返回 `IDEMPOTENCY_KEY_REUSED`。
- 媒体孤儿删除改为数据库标记、删除任务与可重试对象存储删除两阶段流程，不在业务事务提交前删除对象。
- Nginx 会重新解析 Compose 服务地址，API/Web 容器替换后无需重启网关即可恢复，避免缓存旧容器地址造成持续 502。

## 本次已关闭的上线阻断项（代码层）

- 生产冷启动代码：Flyway V8 种子角色；普通 Web 进程不执行引导。授权操作者通过单独的 `production,bootstrap-admin` 无 Web 命令创建首个待激活超级管理员，激活链接只输出到当前终端。该链路仍待候选冷启动复验。
- Actuator readiness 探针显式启用，且 readiness 组包含 `db`；`/healthz` 改为真实探测数据库，避免恒 UP。
- V9 将应用表转换为 utf8mb4，JDBC URL 使用 `characterEncoding=utf8mb4`；数据库默认字符集由基础设施预先配置，迁移不要求 `ALTER DATABASE` 权限。
- 乐观锁映射为 409 `CONTENT_VERSION_CONFLICT`；其他数据库完整性错误使用独立 `DATA_INTEGRITY_CONFLICT`；`revise()` 使用悲观锁，编辑器对版本冲突停止自动保存并引导重新加载。
- 前端门面：`lang=zh-CN`、默认标题/description/OG、动态标题、`robots.txt`、动态 sitemap、全局 ErrorBoundary。
- 本地验收路由仅在本地镜像构建时编入；管理 API 默认「本地验收操作」审计原因已移除。
- Compose 补 `restart: unless-stopped` 与日志轮转；网关补超时与 gzip；Web 静态资源缓存头；发布手册明确禁止扩容。
- 会话改为 Spring Session JDBC（V10），单实例重启不再清空登录态。

## 已取得的本地候选证据

- 已有基线：后端从清理状态执行 `mvnw clean verify`，42 项测试通过；Testcontainers 启动 MySQL 8.4 与 MinIO，Flyway 从空库顺序应用 V1–V7。该证据不替代当前 V1–V10 候选验证。
- 前端 TypeScript、静态检查、11 项组件测试与生产构建通过；OpenAPI 3.1 校验通过。
- Playwright 在最终本地镜像上运行 8 个场景：6 项通过，2 项仅因写入闭环限定桌面端而按设计跳过。
- 浏览器证据覆盖图片上传不跳转、审核完整原文、退回再送审、配额阻断、调整后发布、公开媒体读取、隐藏后内容和媒体 404、账号停用后的会话失效与恢复。
- 本地和生产候选 Compose 均通过配置解析；`/healthz`、公开首页、统一详情直达/刷新和审核详情 SPA 路由返回成功。

## 仍阻止生产上线放行的事项

1. 尚未获得腾讯云、托管 MySQL、COS、密钥管理、邮件、监控、DNS、证书、备案和公网发布授权；没有创建或配置任何外部资源。
2. 数据库与媒体备份、隔离恢复、应用回滚及发布演练尚未在获批测试/生产等价环境执行，因此没有可承诺的实际 RPO/RTO。
3. Java 依赖漏洞检查、前后端 SBOM/许可证清单、契约驱动的前端类型生成和远程 CI 尚未完成；这些仍是 R4/R5 发布门禁缺口。
4. 生产入口的 WAF、边缘限流、日志汇聚、指标采集与告警接收人尚未配置；公开写入限流仍是单实例内存实现，认证限流已落库。
5. 私密联系方式当前不收集。一旦产品批准收集，必须先落实应用层加密、真实密钥托管、访问审批与删除周期，不能直接启用预留字段。
6. 模块定义可驱动当前通用筛选投影，但公开前台仍未自动生成任意多条件组合筛选器；新增复杂筛选仍需随研发版本实现和测试。
7. 未使用真实竞赛、资源、团队招募、合作方、社群入口或联系方式；内容真实性、版权个案、隐私文本和真实运营体验仍需责任主体审批。
8. 纯 SPA 的搜索引擎索引能力有限；当前仅提供动态标题、robots 与 sitemap 基线，预渲染/SSR 列为上线后议题。
9. 候选编排在真实环境的完整启动冒烟（含空库冷启动引导）仍须在 staging 留证；此前仅做过 `compose config` 语法解析。

## 固定外部边界

不创建腾讯云、COS、托管数据库、监控、邮件、DNS、证书或域名资源；不使用真实内容、联系方式、账号或社群入口；不推送远程仓库或部署公网。
