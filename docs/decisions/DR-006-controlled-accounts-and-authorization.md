# DR-006：受控账号、管理员授权与组织成员

状态：APPROVED（2026-10-02 用户确认方案并授权实施）。

## 目标与边界

在现有账号、合作方档案及候选修订上扩展，依次交付安全撤销、管理员授权、单层组织成员。无普通用户注册、个人发布资格、多因素认证、双人审批、自审禁令、多组织成员或角色继承。

## 决策

- 账号使用独立安全版本；会话和一次性凭据绑定安全上下文，资格恢复不复活旧凭据。
- 超级管理员后台密码恢复禁止；仅受控非 Web 运维命令恢复既有超级管理员。
- ADMIN 保留身份，业务能力以固定权限、每项范围及整体期限授权；既有 ADMIN 初始无授权。
- 超级管理员维护授权并预览影响；授权变化写入现有审计，撤销旧会话。
- 合作申请批准仅建立待激活账号，账号运营另行签发激活链接。
- PartnerProfile 是组织业务主体，主账号之外只增加一层子账号。内容、公开内容配额和资格属于组织。
- 成员共享组织候选内容；主账号不占名额，PENDING/ACTIVE/SUSPENDED 占名额，REVOKED 释放且不可恢复。下调限额不自动停用。
- 主账号管理本组织成员激活/恢复，平台恢复主账号。密码由使用者设置。
- 组织停用撤销全部操作资格与旧会话/凭据，不自动撤稿；发布仍由平台审核。

## 工程与迁移

本实验仓库不是产品真源。只追加 Flyway 迁移；保留所有已有账号、档案和内容 ID。每阶段在合成数据上验证后迁移最小变更到产品仓库的 Issue/PR/CI。禁止混合安全版本切换、生产配置、自动部署或生产数据导入。

本决策替代 S-04 和 DR-001 中一对一合作方、普通管理员默认全权及相关恢复边界；其他内容、隐私、公开输入和保留规则不变。
