# DR-005：入口拆分为展示形式、联系渠道和访问级别

## 决定

招募行动入口和社群入口不再使用把平台与展示方式混合在一起的单一类型。统一拆分为：

- 展示形式：`LINK`、`QR_CODE`、`TEXT`。
- 联系渠道：`URL`、`EMAIL`、`WECHAT`、`QQ`、`PHONE`、`OTHER`。
- 访问级别：`PUBLIC`、`COMMUNITY_GATED`。

个人联系方式默认受控。显式公开邮箱、微信、QQ、电话或个人二维码时，管理请求必须携带风险确认。受控值加密存储，审计只记录类型和访问级别，不记录原值。

## 原因

原模型把“如何展示”和“通过什么渠道联系”绑定在同一个枚举中。每新增一个平台都会同时影响数据库约束、接口、前端和公开渲染，且无法自然表达“微信二维码”“电话文本”“其他平台链接”等组合。

## 兼容与发布

项目尚未正式上线，本次采用前后端与数据库同步升级。旧值由新增 Flyway 迁移确定性转换；无法判断个人号或群号时保留原展示名称，并将渠道归入微信、QQ 或其他。回滚依赖发布前数据库快照。
