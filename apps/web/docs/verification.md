# 整站验收说明

## 本次验证结果

- 构建和静态检查通过，无静态检查警告。
- 8 项单元测试、13 项浏览器场景通过。
- 真实公开内容读取正常；模拟写入全部被浏览器测试拦截，没有发送到现有业务服务。
- 首页浅色自动无障碍扫描未发现确定性违规；一处被整卡链接覆盖的装饰性文字需人工判断，已结合截图检查。此检查不等同于整站无障碍认证。
- 2552 / 1920 / 1440 / 1280 / 1024 / 768 / 390px 下完成响应式检查；常用尺寸覆盖首页、搜索、资源列表、详情、反馈、申请、关于、登录、激活、工作台和 404 的浅色/深色布局，无页面横向溢出。
- 宽屏首页首屏高度、页脚网格对齐、页脚总高度、列表尾部提示高度，以及公共正文和页脚可见中文 13px 下限均由浏览器测试约束。
- 图片慢加载前后高度差小于 1px；复制、原生分享不可用时的降级及列表滚动恢复通过。

## 实际服务验证

浏览器读取本地 v0 的 `/api/v1/public/home`，核对首页、三个分类和返回的每个内容链接。
投稿、合作申请、登录、激活、关于、404 和未登录工作台入口均检查可访问性。
真实服务只执行 GET 请求；不向现有数据库提交测试申请、创建账号或更改内容。

## 隔离模拟验证

`e2e/fixtures.ts` 在测试浏览器拦截全部 `/api/v1/**` 请求。未定义的请求返回测试错误，不会落到真实服务。

- 三种反馈提交、合作申请、必填校验和失败保留输入。
- 管理员送审、审核通过、发布、隐藏、重新公开、归档、恢复与操作原因。
- 合作方富文本候选修订；模拟 412 冲突，验证输入保留和原有结构不丢失。
- 申请审批、一次性激活凭据展示、刷新后移除、配额调整和归属转交。
- 主题持久化、跨标签页同步、跟随系统，以及主脚本未执行时的初始主题。
- 服务器查询与游标分页、详情返回、复制链接。
- 聚合搜索正常结果、无结果、单类失败独立重试和全部失败。
- 长文目录、同类内容、类型专属关键信息，以及短文双栏和长文三栏切换。
- 2552 / 1920px 宽屏密度，1440 / 1280 / 1024 / 768 / 390px 常用布局、移动菜单焦点和减少动效偏好。

单元测试额外验证请求头、CSRF、幂等键、If-Match、HTML 代理错误、归档状态操作限制、正文目录提取、截止状态派生和聚合搜索部分失败。

## 真实业务验收边界

管理员和合作方的真实登录、激活及写入端到端流程尚未在本轮执行；以上相关流程由模拟服务验证。正式接管业务前应使用独立测试账号与可处置的隔离数据，再跑一次真实接口验收。

## 后续页面必检项

两套主题下均检查正文、次要文字、表单错误、提示、状态标签、弹窗、加载和空状态；检查窄屏换行、Tab 顺序、焦点回归和路由刷新。公共内容新增中文不得低于 13px，不得使用 `DM Mono` 承载中文；页脚与首页首屏需要同时检查高宽屏密度。
