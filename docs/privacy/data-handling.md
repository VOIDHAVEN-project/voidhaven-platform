# 数据处理与隐私实现基线

- 公开内容与私密联系方式彻底分开：联系方式只进入受限 `private_contact_records`，不进入公开 DTO、前端 fixture、审计明细或常规日志。
- 公共投稿仅接受文字、链接和图片说明；正文图片上传接口需要已认证合作方或管理员。
- 私密联系方式在应用层使用带密钥标识的加密字段保存。当前本地演示不录入真实联系方式。
- 审计只记录最小操作摘要、对象 ID、角色、动作、原因和时间，禁止记录密码、令牌、会话、原始 IP、完整私密正文或联系方式。
- 留存任务的默认周期：幂等记录 24 小时、社群验证事件 7 天、非敏感异常摘要 14 天；真实业务留存周期须由责任主体在生产审批前确认。
