# 受控账号实施规范（DR-006）

2026-10-02 用户批准实施；本文件明确本轮替代规则，历史决策保持可追溯。

## 一、安全与凭据

账号独立 `security_epoch` 绑定登录会话与凭据。激活/恢复凭据还绑定签发人版本；合作方凭据绑定组织版本。任何改密、恢复、资格停用/撤销、授权改变和运维恢复均原子推进安全版本并撤销相关旧会话与未使用凭据。组织状态改变推进组织版本并撤销所有主/成员账号的旧会话和凭据。恢复资格不会恢复旧链接。

锁顺序为组织 ID 升序、账号 ID 升序、凭据、业务对象。写请求在业务事务内持续持有资格锁，检查当前状态和版本，并在业务服务内复查操作权限。内容归属在等待锁期间发生变化时返回冲突。转交只缓存最多 16KB 的转交参数，不缓存密码或上传流。

幂等按账号、安全版本、HTTP 操作及对象路径、客户端键隔离。读取旧结果前执行当前资格、范围和权限检查；原始凭据一次性交付，不写幂等结果或审计。凭据消费失败整体回滚。

超级管理员仅当前密码改密或受控非 Web 恢复。运维入口只恢复既有正常/待激活超级管理员，密码隐藏交互输入，身份标签和原因写审计；不增加额外超级管理员。

## 二、管理员固定能力

ADMIN 身份不提供默认业务权限。权限目录包括内容查看、编辑、审核、发布、来源核验、合作方核验、账号运营、私密查看、归属转交、配额、审计、公开输入以及首页/目录/资源配置。

内容每项权限分别选全平台、栏目列表或组织列表。账号运营、配额、转交、私密查看使用全平台或组织列表；其他全站操作只有全平台范围。每项权限只有一种范围，内容操作权限在自身范围内隐含查看，不扩展其他操作权限。私密查看还要求业务对象访问权；缺少私密权限不得读取受控值、媒体 ID 或整组覆盖含私密条目的行动入口。

授权为一份当前集合，带明确截止时间或显式长期选项、并发版本。创建、预览、更新、部分/全部收回及历史仅超级管理员管理。预览与保存共用校验；授权改变撤销旧会话和凭据，到期按服务端时间判断。既有 ADMIN 初始为空，不保留旧全权窗口。历史复用既有审计保留策略，后台展示最近 100 条；更早保留期内记录可从平台审计查看。

所有后台路由必须声明授权规则。未知入口拒绝，列表与计数按范围过滤，详情与媒体复核对象范围。仅组织范围编辑维护既有组织内容；全平台/栏目编辑可创建平台草稿。转交须同时覆盖源组织和目标组织；平台归属内容只有全平台转交者可处理。

同一人可被授予编辑/审核/发布，仍走提交审核、通过、发布。删除、拒绝稿重开、管理员管理、平台人工密码恢复及既有超级管理员专属入口仍为 SUPER_ADMIN。

合作申请批准仅创建待激活组织主账号，不返回令牌。账号运营人员独立签发激活凭据；具备两项能力者可在界面连续操作。

## 三、组织与成员

PartnerProfile 保持业务主体和主账号关联；新增成员限额、组织安全版本、配置版本和一层成员关系。成员仅复用 PARTNER 账号，不支持自行注册、个人开户、多组织绑定、自定义角色或递归创建。

平台核定限额，既有组织默认 0；实现限额取值 0～1000。主账号不占名额，PENDING/ACTIVE/SUSPENDED 成员占名额，REVOKED 永久释放。创建、资格变更、限额修改均在组织锁内执行；计数使用当前锁定读取，避免 MySQL 一致性旧快照导致并发超额。下调限额不处置现有成员，达到/超过限额只阻止新建。

主账号管理本组织成员创建、激活/恢复、停用、恢复和永久撤销。创建返回待激活成员，独立签发一次性凭据；成员本人设置密码。待激活成员也可停用；恢复后仍保持待激活，需要重新签发链接，不直接开放登录。平台保留账号处理能力，主账号密码恢复由超级管理员处理。成员无法管理成员、配额或平台审核/发布。

成员共享组织候选内容及已绑定媒体，修订冲突沿用 If-Match。未绑定暂存媒体仅上传者可用，不因组织共享或管理员身份扩大。实际操作者写修订/上传/审计，内容、公开配额和发布资格始终属于组织。成员离开保留内容归属和历史。

组织停用阻断所有主/成员操作并撤销旧会话/凭据，单个账号状态独立保留。恢复组织后正常账号重新登录，单独停用账号仍停用。公开内容不自动撤稿，平台自行决定展示状态；公开内容修改生成候选修订，仍须平台审核发布。

## 四、切换与正式迁移

仅追加 V26～V28，保留账号、组织、内容及历史 ID。旧会话与链接失效，普通管理员重新授权，组织成员限额从 0 开启；切换禁止新旧应用混跑。

本仓库只验证合成实验。正式产品需复核最小变更，按 Issue/PR/CI 接入，实际部署、数据库升级和运维恢复另行批准。回退保留安全结构，不重新接受失效凭据或恢复默认管理员全权。
