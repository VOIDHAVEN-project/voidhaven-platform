# VOIDHAVEN Memoir 前端开发约定

- 本项目独立于 `D:\voidhaven\v0`。允许为版本跟进只读核对其 OpenAPI、控制器和原业务前端行为；永久禁止修改、格式化、构建覆盖、数据库迁移或提交该目录。
- 以运行中的 v0 接口为契约基准。保持 Cookie、CSRF、幂等键和候选修订版本校验；不要套用其他 VOIDHAVEN 版本的接口。
- **明暗主题为持续要求**：每个新页面和组件都必须支持浅色、深色与跟随系统，复用 `ThemeProvider` 和 `ThemeButton`。保留 `voidhaven-theme` 键；不得在页面内部重新初始化主题。
- 颜色使用公共语义变量。新增表单、提示、状态标签、空状态、弹窗和加载状态必须同时验收两套主题；不得仅处理页面背景。
- 保留暖灰纸面、墨色文字、低饱和强调色与编辑式排版；公开站使用顶部导航，后台使用窄侧栏。公共正文基准 16px，后台表单基准 14px。
- 公开站头部导航是视觉基准，公共页面重构不得随意改变其结构、字号和主题交互；先进行浏览器回归再调整共享样式。
- 公开正文与页脚中的可见中文不得低于 13px。中文使用系统优化无衬线字体且不增加字距；`DM Mono` 只用于纯英文标签、编号和日期，不得承载中文。
- 公共页面使用统一间距尺度，模块间距原则上不超过 80px；不得用视口高度、空容器或大外边距制造无内容的留白。
- 公共搜索只能复用真实分类接口并明确分组，不展示后端未提供的全站总数、热度或推荐指数。长详情页可显示页内目录，短内容不得为了布局而填充空栏目。
- 搜索、分页和权限由真实接口支持。严禁用模拟数据掩盖接口错误，测试数据必须隔离在测试目录与浏览器拦截中。
- 新建内容使用服务端模块模板；编辑时同时保留 Markdown 原文、服务端正文、语言、来源、授权、媒体和类型专属字段。服务端安全解析结果始终是最终权威。
- 管理审核必须携带当前修订的 `If-Match`；发生冲突时保留本地输入，不自动覆盖。公开表单和媒体上传的同一逻辑提交必须复用幂等键。
- 不为未进入 OpenAPI 和原业务前端的永久删除、社群验证等接口创建入口。
- 密码、激活凭据和受控正文不得存入 localStorage、sessionStorage、日志或 URL 新参数。主题与侧栏偏好允许本地保存。
- 手机菜单须支持焦点管理、Escape 关闭和焦点恢复；低动效模式下全部操作可用。
- 实施变更后运行构建、静态检查及相关测试。真实写入验收必须使用明确隔离的测试数据；不得操作已有业务记录来“验证”。
- 默认只在本地展示，不公开部署、不绑定域名。
