# 正式上线候选阻断项与已知限制

更新日期：2026-09-03。本文只记录当前代码和验证的真实状态，不构成上线批准。

## 已实现且经本地质量门验证

- 公开三栏目浏览、来源说明页、基础服务端筛选/游标分页、SPA 刷新 fallback。
- 公开投稿和合作方申请的幂等请求与异步表单重置回归。
- 管理员内容创建、送审、审核、发布、隐藏、重新公开、归档与恢复；合作方草稿、编辑候选修订、送审、配额和归属控制。
- 一次性短时激活令牌（仅存哈希）、账号资格检查、CSRF、幂等冲突、富文本白名单、CSP、审计摘要与留存清理任务。
- 公开写入有短窗口限流和 HTTPS 链接校验；限流键只在内存保留带密钥摘要，生产配置必须注入独立密钥。
- 合作方和管理员可仅对自己的候选修订上传 JPEG、PNG、WebP 正文图片；服务端会解码校验、重编码清除输入元数据、限制数量和总量，并以私有 S3/MinIO 键保存。公开读取按已发布修订的关联关系受控，未关联媒体由留存任务加锁复核后清理；该代码和单元测试已通过，尚无 MinIO 集成演练。
- 公开内容使用受限语言值与中文显示标签；非中文内容必须留存原始标题。作者展示名、权利来源、署名转载与署名改编许可独立保存并在公开详情呈现，尚无空库 V5 或浏览器闭环证据。
- 本地与生产候选 Compose 配置解析、前端构建/测试、后端 `mvn verify` 可运行包。

## 未完成或尚未获得验证证据：阻止发布候选放行

1. 已完成空库 Compose、Flyway（V1–V3）、公开首页、详情直达/刷新和健康检查的 Smoke Test；Testcontainers 也已在干净 MySQL 上验证 V1–V5 迁移。但包含 V4/V5 的 Compose 空库重建、管理员浏览器闭环、CSRF、隐藏后 404、真实 MySQL 事务断言及恢复脚本演练仍未完成。
2. S3/MinIO 私有媒体上传、真实格式/尺寸验证、输入元数据清除、受控读取和媒体孤儿清理已经实现并有单元测试；Testcontainers 已验证私有 MinIO 桶可写、读、删，但尚未取得 WebP 样本、受控公开读取、失败重试和清理任务的完整集成证据。允许正文图片进入发布候选前，此项仍是阻断项。
3. Testcontainers MySQL/MinIO 集成测试、Playwright E2E、OpenAPI 自动校验/前端类型生成、依赖漏洞/许可证/SBOM 检查尚未完成。
4. 私密联系方式当前不收集；一旦产品批准收集，必须先实现应用层加密、受控密钥、删除周期和对应集成测试，不能直接启用预留数据列。
5. 备份、隔离恢复、应用回滚和发布演练仍无实际 RTO/RPO 证据。
6. 公开写入限流尚未完成反向代理链、重启行为和 7 天匿名限流事件留存的集成验证；它不能替代生产入口的 WAF/网关限流策略。

## 外部审批边界仍然有效

不创建腾讯云、COS、托管数据库、监控、邮件、DNS、证书或域名资源；不使用真实内容、联系方式、账号或社群入口；不推送远程仓库或对公网部署。
