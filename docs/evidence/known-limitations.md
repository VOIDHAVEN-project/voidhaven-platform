# 正式上线候选阻断项与已知限制

更新日期：2026-09-15。本文记录当前候选的真实边界，不构成生产上线批准。

## 已关闭的代码与本地验收阻断项

- 首页“申请成为合作方”已进入申请流程，不再误导至社群入口。
- 来源核验已形成管理员创建、历史留痕、公开详情展示、复核日期和异常待办闭环。
- 密码恢复采用双通道：保留超级管理员人工签发与交付留痕，同时支持用户绑定并验证恢复邮箱后自助找回。
- 人工和自助重置凭据按类型隔离；凭据均为短时、一次性、仅存摘要，成功改密会注销全部会话并撤销两类其他凭据。
- 公开找回响应不暴露账号或邮箱是否存在，网络和登录名维度分别限流；恢复邮箱加密保存，只向用户展示脱敏值。
- Web、OpenAPI、API、Flyway 和浏览器全栈门禁均已在本地通过；隔离测试数据卷已删除。
- 本地示例内容只在 `local` profile 初始化，标题与正文明确标记“示例/合成”，生产 profile 不执行该初始化器。

## 仍阻止生产上线放行的事项

1. 尚未在获批生产等价环境配置真实 SMTP、AES 密钥环、数据库、对象存储、TLS、域名、备案、WAF、监控与告警；仓库仅提供变量契约和 fail-fast 校验。
2. 真实环境的数据库/媒体备份、隔离恢复、发布切换和回滚演练尚未留证，不能承诺实际 RPO/RTO。
3. 当前验收使用合成账号、内容和本地邮件接收器；真实邮件送达率、退信处理、运营人员交付流程和真实用户全链路 UAT 尚待责任主体执行。
4. 正式内容的真实性、版权依据、隐私文本、合作方、社群入口和联系方式仍需内容及法务责任人逐项审批，不能用自动化测试代替。
5. Java 依赖漏洞扫描、前后端 SBOM/许可证清单仍需纳入正式供应链门禁。
6. 纯 SPA 的搜索引擎索引能力有限；当前只有动态标题、robots 与 sitemap，预渲染/SSR 仍为后续优化。
7. 当前多实例安全依赖 MySQL 共享状态和非混合版本切换；生产首次切换应保持单 API 实例，冒烟通过后再扩容。

- RC：不通过；须先完成上述生产等价环境验证与真实用户 UAT。
- 生产上线：未授权，也未执行。
