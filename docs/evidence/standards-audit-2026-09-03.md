# VOIDHAVEN V0 规范符合性审核（2026-09-03）

## 结论

当前仓库是**本地正式上线候选的在建版本**，不是可以放行的正式上线版本。公开发现、受控账号、审核状态机、配额、审计、来源限制、受控媒体和候选容器形态已有可追溯实现；但 R4/R5 所要求的真实集成验证、跨路由浏览器证据和恢复演练仍缺失。任何公网、真实数据或生产发布继续被本审核明确阻断。

本次只读比对的批准基线为 `D:\Projects\docs\standards\S-01` 至 `S-08`、`DR-001` 至 `DR-004`、`CURRENT.md`；代码与证据取自本独立仓库。`D:\Projects` 未被修改。

状态含义：**符合**=已有实现和当前证据；**部分符合**=有实现但存在规格缺口或证据不足；**阻断**=不允许作为正式发布候选放行。

## 发布阻断项（按优先级）

### P0：不得进入正式发布候选放行

1. **R4 测试证据仍不足。** 已有干净 MySQL/MinIO 容器验证，但无 V4/V5 Compose 空库迁移、Playwright 高风险路径、受控 CSRF/越权/隐藏 404 浏览器证据。单元和存储基础测试不能替代这些验证。
2. **R5 恢复能力未验证。** 没有数据库与媒体同一恢复点的备份、隔离恢复、回滚演练或实际 RTO/RPO；按 S-08，未验证恢复的备份不能视为可靠备份。
3. **生产环境未获授权且未被验证。** 腾讯云、域名、备案、DNS、TLS、告警接收人、密钥、真实内容/账号和任何公网部署均保持禁止状态。

### P1：应在 R3/R4 收口前修复

1. 建立正文图片块和排序模型，令媒体在安全富文本文章中的位置可表达，而非只能附在正文后。
2. 添加 `npm run format` 的可重复检查、OpenAPI 校验/类型生成、依赖漏洞/许可证/SBOM 检查。
3. 在空库迁移、后台创建和公开详情中验证语言标签、外语原始标题、作者展示名和复用许可的完整链路。
4. 将媒体、归属转交、配额并发、到期三天、匿名提交限流和留存清理加入真实数据库/对象存储集成测试。

### P2：发布准备中必须留档

1. 为每个环境变量登记用途、环境、敏感性、拥有者、最后验证时间和轮换/失效方式；样例文件只保留变量名和占位值。
2. 明确候选监控的字段、留存、访问者、告警接收人和关闭/删除方式；不发送正文、凭据或私人资料。
3. 用真实但获批准的测试环境完成测试部署、迁移、Smoke Test、备份恢复和回滚演练后，才能关闭 R5。

## 已在审核中修正的风险

- 发现公开媒体 `max-age=5min` 会让隐藏内容在缓存中短暂继续可读后，已改为 `Cache-Control: no-store`，并新增控制器回归测试。
- 媒体上传和受控读取此前未列入 OpenAPI；现已补入契约。契约自动校验仍为未完成项。
- 结构化语言/权利缺口已由 V5 修复，并新增语言策略和非中文原始标题的后端回归；空库迁移与浏览器路径验证仍未完成。

## 审核判定

项目可以继续在**独立本地仓库**推进 R3–R5，但当前不得标记为“正式上线候选通过”，不得使用真实内容/联系人/社群数据，也不得创建或配置任何云端或公网资源。下一实施重点为：先消除语言/权利数据模型缺口和质量门缺口，再进行获验证的集成、浏览器和恢复演练。
