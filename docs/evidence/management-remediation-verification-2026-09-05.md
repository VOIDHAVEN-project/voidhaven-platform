## 浏览器闭环

```text
合作方登录
  → 创建并保存 Markdown 草稿
  → 上传并插入正文图片（不离开编辑器）
  → 保存并送审
管理员登录
  → 打开审核原文与图片
  → 退回并填写原因
合作方重新编辑并送审
管理员将配额设为 0
  → 审核通过
  → 发布被明确阻断
恢复配额
  → 发布成功
  → 公开内容及媒体可读
  → 隐藏后内容及媒体均为 404
```

另有独立场景验证：超级管理员停用合作方后，合作方原有会话的下一次请求立即返回 401；恢复账号后本地合成账号回到可用状态。

## 额外修复

- 最终环境替换 API 容器时发现 Nginx 缓存旧容器地址会造成持续 502；已改为通过 Docker 内部 DNS 定时重新解析，并实际验证网关无需重启即可恢复健康。
- 编辑器增加 2 秒自动保存、保存状态、版本冲突保护、未保存离开/退出确认；服务端退出失败时页面不会强制跳回首页。
- 后台列表补充分页、筛选、失败重试和空状态；审计检索补充操作人、对象、动作和时间范围。
