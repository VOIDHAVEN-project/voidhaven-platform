# VOIDHAVEN 规范目录

本目录存放项目的八份持续规范。它们共同覆盖产品决定如何形成、如何用 Codex 开发、做到什么范围、数据如何治理、页面如何实现、接口如何协作、怎样验证和怎样上线。

| ID | 名称 | 批次 | 当前状态 |
| --- | --- | --- | --- |
| S-01 | 规格治理与决策管理规范 | 第 1 批 | APPROVED |
| S-02 | Codex 协作与模块开发规范 | 第 1 批 | APPROVED |
| S-03 | 产品需求范围与版本路线图规范 | 第 2 批 | APPROVED |
| S-04 | 领域、权限、内容、数据生命周期与隐私规范 | 第 2 批 | APPROVED |
| S-05 | 信息架构、界面与可访问性规范 | 第 3 批 | APPROVED；2026-08-30 随第 3 批合入 docs/main 生效 |
| S-06 | 前后端 API 与数据契约规范 | 第 3 批 | APPROVED；2026-08-30 随第 3 批合入 docs/main 生效 |
| S-07 | 工程实现、质量与测试规范 | 第 4 批 | APPROVED；2026-08-30 随第 4 批合入 docs/main 生效 |
| S-08 | 上线、运维、备份、回滚与安全基线规范 | 第 4 批 | APPROVED；2026-08-30 随第 4 批合入 docs/main 生效 |

S-03、S-04 是当前已批准的产品与数据结论；S-05、S-06 是当前已批准的页面、可访问性与接口契约结论；S-07、S-08 是当前已批准的工程质量与运行基线。每一批必须先由项目负责人审核和批准，才会进入下一批。

第 2 批使用 DR-001 至 DR-004 对账号归属、提交/最小日志、富文本/图片/版权、内容语言与外语资源等跨规范问题进行答辩。四份 DR 的推荐方案及本批开放项结论已获项目负责人整体批准，并已回填 S-03、S-04 后合入 `docs/main`。
