# 备份与恢复预案

## 本地/测试

- 数据库导出使用 `infra/scripts/backup-local.ps1`，备份文件只写入调用方明确指定且属于实验目录的目录。
- 恢复脚本默认仅做校验；必须显式传入 `-Apply` 才会写入数据库。恢复前应先在隔离环境验证 SQL、迁移版本、内容引用和权限投影。
- MinIO 媒体需要与数据库清单同一恢复点核对；不可把数据库成功导入误判为完整恢复。

## 候选生产（未经授权，不执行）

推荐 RPO 不超过 24 小时、RTO 不超过 4 小时。使用私网托管 MySQL 的每日备份/时间点恢复能力，以及私有 COS 主桶与受限备份副本。每季度在隔离环境演练：恢复数据库、运行迁移校验、核对媒体、抽查公开 404 隐藏语义、账号资格与审计可用性。

删除或侵权下线后，主存储立即删除/隐藏，备份副本按最终批准的最长 14 天窗口清理。备份不能成为无限期保存私密数据的理由。
